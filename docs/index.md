# Бази даних

Навчальний посібник до дисципліни **«Бази даних»**. Теорію кожної теми супроводжують
практичні приклади на **Microsoft SQL Server (T-SQL)**. Усі приклади виконуються на одній
[тестовій базі даних `UniversityDB`](database.md), яка моделює роботу університету.

## Як працювати з прикладами

1. Встановіть SQL Server 2019 або новіший (безкоштовні редакції **Express** чи **Developer**)
   або запустіть його в Docker:

    ```bash
    docker run -d --name mssql -e ACCEPT_EULA=Y -e MSSQL_SA_PASSWORD='Str0ng_Passw0rd!' \
      -p 1433:1433 mcr.microsoft.com/mssql/server:2022-latest
    ```

2. Підключіться через **SQL Server Management Studio (SSMS)**, **Azure Data Studio** чи
   розширення **mssql** для VS Code.
3. Виконайте по черзі скрипти зі сторінки [Тестова база даних](database.md).
4. Відкривайте тему і виконуйте приклади. Ті, що змінюють дані, можна повторювати:
   просто перезапустіть скрипти 1–3, щоб повернути базу до початкового стану.

!!! tip "Позначення"
    Блоки **«Результат»** показують, що повертає запит на тестових даних.
    Коли приклад потребує **двох одночасних сеансів** (Тема 8), відкрийте два вікна запитів у SSMS.
