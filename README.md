# DB Tutorial

Source for the tutorial site at https://shpil1993.github.io/DBTutorial/, built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

## Edit locally

```bash
pip install -r requirements.txt
mkdocs serve   # preview at http://127.0.0.1:8000
```

Pages live in `docs/`; navigation is set in `mkdocs.yml`. Pushing to the default branch deploys the site to the `gh-pages` branch via GitHub Actions.
